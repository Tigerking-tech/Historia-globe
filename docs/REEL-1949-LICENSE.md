1. **财产权可能已届满，但不能直接认定公版。** 若该片被认定为 1949–1951 年首次发表的视听/电影类作品，依当时及现行规则的「发表后 50 年」口径，财产权可能已于 2001 年前后届满。但若被认定为录像制品、或所用为后来的**修复版 / 数字化版 / 汇编节目**，权利起算点不同，不能一概认定为公有领域。
2. **人身权永久受保护。** 署名权、修改权、保护作品完整权不因财产权届满而消灭。本项目做了裁切、烧字幕、加角标、配音，涉及修改权与保护作品完整权，须保持作品与来源不被歪曲、割裂。
